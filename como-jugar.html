Cómo jugar en AngryLove

Todo lo que necesitas para entrar desde Minecraft Java Edition.

IP del servidor · Java Edition

angrylove-node.duckdns.org

Versión de Minecraft:

Paso a paso

  1. 1

    Abre Minecraft Java

    Inicia el launcher y entra en Minecraft Java Edition.

  2. 2

    Añade el servidor

    Ve a Multijugador → Añadir servidor e introduce angrylove-node.duckdns.org.

  3. 3

    Entra al Lobby

    Al conectarte aparecerás en el Lobby, el punto de partida de la red.

  4. 4

    Elige SMP

    Usa la brújula (selector de servidores) o escribe /server smp.

Recuerda: AngryLove es una red. Siempre entras primero al Lobby y desde ahí seleccionas SMP; esta web no puede cambiarte de servidor dentro del juego.

Preguntas frecuentes

¿Cuál es la IP?+

angrylove-node.duckdns.org

¿Necesito escribir el puerto?+

Normalmente no. Se utiliza el puerto por defecto de Minecraft Java, 25565. Si tu cliente lo pide, usa angrylove-node.duckdns.org:25565.

¿Entro directamente al SMP?+

No. Primero entras al Lobby y desde ahí eliges SMP con la brújula o con /server smp.

¿Es para Bedrock?+

Por ahora solo anunciamos compatibilidad con Minecraft Java Edition.

¿Qué versión necesito?+

La versión compatible aún está pendiente de confirmar. Se publicará aquí en cuanto esté verificada.

No puedo entrar, ¿qué hago?+

Comprueba que usas Minecraft Java Edition y que la dirección está bien escrita, sin espacios. Verifica tu conexión a internet y la versión del cliente, y vuelve a intentarlo en unos minutos por si el servidor no está disponible en ese momento.

¿Listo para entrar?

Copia la IP, añádela en Minecraft Java y te esperamos en el Lobby.
